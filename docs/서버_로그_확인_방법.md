# 서버 로그 확인 방법

## 방법 1: 서버를 포그라운드로 실행 (추천)

서버를 새 터미널 창에서 직접 실행하면 모든 로그를 실시간으로 볼 수 있습니다:

```powershell
cd C:\aiavata
python start_backend.py
```

이렇게 하면:
- ✅ 모든 로그가 콘솔에 직접 출력됨
- ✅ 실시간으로 로그 확인 가능
- ✅ Ctrl+C로 서버 종료 가능

## 방법 2: 로그 파일 확인

서버가 로그 파일에 출력하도록 설정되어 있다면:

```powershell
# logs 디렉토리 확인
Get-Content logs\*.log -Tail 50 -Wait
```

## 방법 3: 현재 실행 중인 서버 확인

백그라운드로 실행 중인 서버의 PID 확인:

```powershell
Get-NetTCPConnection -LocalPort 8000 | Select-Object OwningProcess
```

## 추천 방법

**새 PowerShell 창을 열어서:**
1. `cd C:\aiavata` 명령 실행
2. `python start_backend.py` 명령 실행
3. 서버 로그를 실시간으로 확인

이 방법이 가장 간단하고 확실합니다!
